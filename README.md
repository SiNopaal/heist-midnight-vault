THE LAST LIGHT — a top-down museum heist in one static page. Slip past patrolling guards and their sight cones, dodge the sweeping camera, use cover and smoke, palm the moonstone and get out clean. No build step, no network.

## Run it

```sh
node main.ts
```

Then open `output/game/index.html` in a desktop browser. Play with WASD/arrows, `E` to interact, `Q` to drop a coin decoy and `F` for smoke.
